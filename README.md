## Über das Projekt

Die Logos sind so angepasst, dass sie auf dunklen Hintergründen gut funktionieren. Einige Logos sind nicht für helle Hintergründe geeignet. Da die GitHub-Oberfläche weiß ist, kann es so aussehen, als würde ein Logo nicht geladen werden. In Wirklichkeit ist es geladen. Rechtsklicke auf das Logo und wähle "Bildadresse kopieren", um die URL zu verwenden.

## Namenskonvention

Dateinamen sind kleingeschrieben und beginnen mit dem Sendernamen, gefolgt von einer Nummer, falls nötig, und dem Länder-Code am Ende. Leerzeichen werden durch Bindestriche ersetzt.

Beispiele: `abc-7-koat-us.png` | `discovery-channel-us.png` | `syfy-br.png` | `fox-crime-it.png` | `kanal-5-se.png`

Zeitversetzte Kanäle werden mit `plus` gekennzeichnet, z. B. `challenge-plus-uk.png`.

Wenn ein Ampersand (`&`) im Namen vorkommt, wird es durch `and` ersetzt, z. B. `a-and-e-us.png`.

Horizontale Versionen erhalten `hz` im Namen, falls es auch eine normale Version gibt, z. B. `bbc-world-news-hz-uk.png`.
